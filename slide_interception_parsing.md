# Слайд: Перехват и синтаксический анализ

Один слайд, не более 5 тезисов. Опора: гл. 3 (перехват), гл. 4 (анализатор), гл. 5 (исполнение).

---

## Заголовок
**Перехват CUDA Runtime и синтаксический анализ PTX**

## Тезисы (≤ 5, выносить дословно)

1. **Перехват через `LD_PRELOAD`:** `libemuruntime.so` подменяет `libcudart.so`
   на уровне ABI — перехвачено 8 функций CUDA Runtime API, PTX извлекается
   через `cuobjdump`.

2. **Однопроходный линейный анализатор на `std::regex`:** конечный автомат,
   сложность O(N), без AST и внешних генераторов.

3. **Разбор один раз → исполнять много раз:** РВ переводит строку PTX
   в типизированные поля; в горячем цикле — один виртуальный вызов `Execute()`.

4. **Существенное ускорение** относительно интерпретации прошлых версий
   (там строка разбиралась заново на каждой инструкции).

5. **Прозрачный запуск:** перекомпиляция не нужна — `cuemu ./my_cuda_app`
   вместо `./my_cuda_app`.
