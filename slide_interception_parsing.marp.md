# Перехват CUDA Runtime и синтаксический анализ PTX

1. **Перехват через `LD_PRELOAD`** — `libemuruntime.so` подменяет `libcudart.so` на уровне ABI: 8 функций CUDA Runtime API, PTX извлекается через `cuobjdump`.

2. **Однопроходный анализатор на `std::regex`** — конечный автомат, сложность O(N), без AST и внешних генераторов.

3. **Разбор один раз → исполнять много раз** — регулярные выражения переводят строку PTX в типизированные поля; в горячем цикле один виртуальный вызов `Execute()`.

4. **Существенное ускорение** относительно интерпретации прошлых версий, где строка разбиралась заново на каждой инструкции.

5. **Прозрачный запуск** — без перекомпиляции: `cuemu ./my_cuda_app` вместо `./my_cuda_app`.
